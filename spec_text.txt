상태가 되고, 그 결과는 부장 화면에 곧바로 노출되지 않는다 (반드시 말로 전달해야 하는 구조 유지). ④ 인턴·사원·차장 3명 모두 &apos;확인 완료&apos;가 되어야 부장 화면의 &apos;최종 제출&apos; 입력창이 활성화된다. ⑤ 부장이 세 사람에게 들은 내용을 종합해 최종 정답을 제출하면 정답 판정 후 다음 단계로 전환된다. ⑥ 기기를 돌려쓰는 경우, 직급을 바꿀 때마다 화면 상단에 &apos;현재 로그인: OOO&apos; Firebase Hosting (권장) GAS를 완전히 벗어나 정적 사이트로 배포. 모던 JS(ES6+)와 Firebase JS SDK를 그대로 사용할 수 있어 개발이 가장 단순하다. B. 기존 GAS 유지 + Firestore 연동 Index.html은 그대로 GAS에 두고, 클라이언트 JS에서 Firestore REST API 또는 경량 SDK로 데이터만 읽고 쓴다. ES5 제약이 이어질 수 있으니 Firestore 호출 부분만 별도 iframe이나 fetch 기반으로 분리하는 편이 안전하다. 파일 내용 index.html 부서용 메인 화면 (0~8번 화면을 SPA로, 화면 전환은 JS로 처리) dashboard.html 교사용 대시보드 (부서별 진행 트랙 + 환경 게이지, onSnapshot 실시간 구독) firebase-config.js Firebase 프로젝트 초기화 설정 puzzle-data.js 문항·카드 텍스트, 이미지(base64 또는 Storage URL) 상수 style.css 공통 스타일시트 A안(Firebase Hosting) 기준으로는 ES5 제약 없이 최신 문법을 사용할 수 있다. 이미지가 필요한 카드(원단 견본 등)는 base64 인라인 또는 Firebase Storage URL 중 선택하고, 화면 전환은 SPA 방식으로 페이지 새로고침 없이 처리한다. 7. 애니메이션·연출 체크리스트 카드 flip: CSS 3D transform (perspective + rotateY) 잠금 해제: 아이콘 흔들림 → 페이드아웃 → 다음 콘텐츠 페이드인 인벤토리 획득: 슬롯에 아이콘이 튀어 들어오는 bounce 효과 게이지 상승: width% 애니메이션 트랜지션(0.5~1초) 팀 진행 트랙(대시보드): 아이콘 이동 시 위치 값 트랜지션 8. 개발 우선순위 1순위: 화면 0~1(팀 입장·오프닝) — 잠금 해제 트릭과 기본 정답 판정 로직 확인 2순위: 화면 2~4(1~3단계) — 역할 선택 모달 패턴과 자동 채점 로직 3순위: 화면 5~7(제출·개인·소감) — 데이터 저장 완결 4순위: 화면 8·대시보드 — 점수 집계, 학급 게이지, 실시간 폴링 5순위: 애니메이션·연출 다듬기
